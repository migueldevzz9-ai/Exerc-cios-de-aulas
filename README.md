# 📚 Exercícios e Práticas de Programação

Este repositório reúne os exercícios, atividades e códigos desenvolvidos durante as aulas da graduação em **Engenharia de Software**.

Os conteúdos disponibilizados correspondem aos estudos realizados em sala de aula, nos quais foram aplicados os conhecimentos adquiridos para a resolução de problemas e o fortalecimento da lógica de programação utilizando **Python**.

---

## 📖 Sobre o Repositório

Este repositório tem como objetivo organizar os exercícios desenvolvidos ao longo das disciplinas da faculdade, servindo como registro da minha evolução acadêmica e prática na programação.

Cada atividade foi proposta para desenvolver habilidades essenciais na resolução de problemas, aplicação de conceitos fundamentais da programação e construção de algoritmos.
